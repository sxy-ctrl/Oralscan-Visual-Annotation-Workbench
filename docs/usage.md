# 视觉标注工作台 · 开放文献演示版

双击 index.html 打开。分享时发送整个目录或同级分享包，无需联网和安装依赖。

## 本次更新

以两个公开发表的真实临床病例数字牙列截图，替换原来的抽象合成示例。每个病例包含一张原始论文多视图图版，可放大或以原始分辨率查看。原图未裁剪、未重绘，没有重新生成牙齿或补造视图。

素材是论文中的 ClinCheck 多视图截图，不是原始 STL / PLY 口扫文件，不能旋转或执行精确测量。不提供原论文未公开的患者原始数据，也不提供虚构接触热图或初始目标叠加图。原图中的软件界面、商标与标记保持原样，不表示与原软件存在合作关系。

## 如何演示

1. 在两个文献病例之间切换，点击大图查看真实数字牙列形态。
2. 在上颌、下颌、咬合三组中选择类别，演示规则驱动的标注流程。
3. 共 6 项、9 个区域；0 / 1 / 2 分为自定义交互演示分值，不是论文的评分规则、研究结论或临床诊断。
4. 当截图不足以观察时选择“无法判断”或“示意参照缺失”，保留草稿并进入复核状态。
5. 使用异常标签、备注、漏标检查、确认完成及 CSV / JSON 导出。
6. 可导入“examples/demo-backup.json”恢复虚构的操作进度。预填标注不是论文专家答案。

标注人可手动填写，作为整份结果的署名，随浏览器暂存并写入 JSON / CSV。确认完成前需填写标注人；该字段不验证身份，也不分配任务。修改姓名后，重新导出的全部结果使用当前姓名。备注只填写演示内容。无患者资料或原始模型上传入口。导入只接受本演示数据集，不能导入业务版和此前合成版的进度。浏览器暂存采用独立的新标识，不会加载旧进度。

## 界面样式

公开版沿用普通工作版的完整样式表，包含颜色、字号、间距、侧栏、工作区、按钮与响应式布局。已移除额外顶部演示横幅；素材来源及许可说明保留在现有说明区域内。

## 展示文案

主界面统一使用“测试集病例”，用于标注流程演示。素材的真实来源、作者、图号与许可仍在页面“素材来源”及 ../ATTRIBUTION.md 中保留；测试集命名不表示本项目自行采集病例。

## 多视图排列

主影像区以 CSS 裁切显示并重排原图已有视图：上排右侧、正面、左侧；下排上颌、下颌。没有补造斜视图。大图查看仍展示完整论文原图。此为展示布局改编，原始图片文件未修改。侧别标注依原图排列，未经原始模型方向验证。

## 固定视图入口

保留上颌视图、下颌视图、咬合视图、接触图、初始位叠加五个按钮。前三项切换原始图版对应区域，后两项显示缺图说明；无图时禁用缩放与大图工具。
