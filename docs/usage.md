# 操作说明

1. 填写标注人，选择测试集病例。
2. 使用上颌视图、下颌视图、咬合视图、接触图、初始位叠加按钮切换查看。缺少对应图像时显示缺图说明。
3. 在各分组选择类别，按需记录异常 Tag 与备注。无法判断时保留为待复核状态。
4. 标注完整后确认完成。后续修改会恢复为草稿。
5. 导出 JSON 备份或 CSV 结果。导入 JSON 将替换当前工作区，请先备份。

标注人为整份工作区的署名，不验证身份，不分配任务。修改后重新导出的全部记录使用当前署名。

进度保存在当前浏览器的 localStorage 中，不自动上传。更换浏览器、地址或清理浏览器数据后，可导入 JSON 恢复。

主影像区对原图已有视图进行裁切排列，大图查看显示完整原图。侧别未经原始三维模型方向验证；图片原文件未修改。来源与许可见根目录 ATTRIBUTION.md。
