# Visual Annotation Demo

一个静态、离线可用的视觉标注演示项目。主界面采用测试集命名，图片来源于已发表的临床病例，评分规则仅用于交互演示。无后端、登录、统计埋点或数据上传接口。

## 本地运行

可直接用浏览器打开 `index.html`。安装 Node.js 18 或更高版本后，也可以运行：

```sh
npm start
```

访问 http://127.0.0.1:8080 。没有第三方依赖，无需 npm install。

```sh
npm run check
```

执行源码语法、资源引用、素材哈希和基础敏感字段检查。

## 项目结构

```text
index.html                页面入口
src/                      应用逻辑和样式
assets/images/            两张公开授权图版
data/                     演示数据及素材清单
examples/                 虚构的标注备份示例
docs/                     使用说明和公开前检查记录
scripts/                  本地预览与检查脚本
ATTRIBUTION.md            图片来源及 CC BY 4.0 署名
LICENSE.md                权利范围说明
```

## 功能

病例切换、五个固定视图入口、图片区域重排、缩放、标注署名、类别记录、异常标签、复核状态、本地暂存和 JSON / CSV 导出。没有对应素材的接触图与初始位叠加入口显示缺图说明。

标注人为整份工作区的署名，可编辑；不是认证身份或病例分配。修改后导出的全部结果使用当前署名。浏览器数据不会随代码上传，但手动导出的文件可能包含输入的姓名和备注，请勿提交个人工作备份。

## GitHub 上传

请只上传本目录，不要上传其上级工作目录、原始数据、工作簿或内部项目。本项目不依赖本机绝对路径。可作为静态站点部署；GitHub Pages 选用仓库根目录即可，不需要构建步骤。

两个公开临床图版来自 Caruso 等（2021）论文，采用 CC BY 4.0。它们是数字牙列截图而不是原始 STL 文件。请保留 [素材署名](ATTRIBUTION.md)。图像来源与许可不表示原作者为本项目背书。代码权利范围见 [LICENSE.md](LICENSE.md)。
